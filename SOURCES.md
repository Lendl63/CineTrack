# Sources et Ressources du Projet CineTrack

Ce document répertorie les bibliothèques, API, polices et outils utilisés pour le développement de l'application **CineTrack**.

## 1. Bibliothèques de Gestion d'Images
*   **Glide** : Utilisé pour le chargement, l'affichage et la mise en cache des affiches de séries et images de fond.
    *   Lien : [https://github.com/bumptech/glide](https://github.com/bumptech/glide)

## 2. API de Données
*   **TMDB (The Movie Database)** : Fournit toutes les métadonnées sur les séries (titres, dates, synopsis, notes, images).
    *   Lien API : [https://developer.themoviedb.org/docs/getting-started](https://developer.themoviedb.org/docs/getting-started)
    *   Site : [https://www.themoviedb.org/](https://www.themoviedb.org/)

## 3. Composants d'Interface (UI)
*   **Material Components for Android** : Fournit les composants de design (boutons, champs de saisie, cartes).
    *   Lien : [https://github.com/material-components/material-components-android](https://github.com/material-components/material-components-android)
*   **ConstraintLayout** : Système de mise en page flexible pour Android.
    *   Lien : [https://developer.android.com/reference/androidx/constraintlayout/widget/ConstraintLayout](https://developer.android.com/reference/androidx/constraintlayout/widget/ConstraintLayout)

## 4. Polices de Caractères
*   **Rajdhani** : Famille de polices utilisée pour l'identité visuelle de l'application.
    *   Lien : [https://fonts.google.com/specimen/Rajdhani](https://fonts.google.com/specimen/Rajdhani)

## 5. Outils et Frameworks
*   **Android SDK** (API 36) : Plateforme de développement.
    *   Lien : [https://developer.android.com/studio](https://developer.android.com/studio)
*   **Gradle** : Système de gestion de build (Kotlin DSL).
    *   Lien : [https://gradle.org/](https://gradle.org/)
*   **Java (JDK 11)** : Langage principal pour la logique métier.
    *   Lien : [https://www.oracle.com/java/technologies/downloads/](https://www.oracle.com/java/technologies/downloads/)

## 6. Iconographie
*   **Google Material Icons** : Base des icônes utilisées dans l'interface.
    *   Lien : [https://fonts.google.com/icons](https://fonts.google.com/icons)
